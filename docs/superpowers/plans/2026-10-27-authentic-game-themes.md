# NavSkin 0.6 · plano e contrato visual

Pedido: arquivos autênticos dos jogos na tipografia/ícones e GTA calibrado aos três screenshots fornecidos. Preservar GPS, rotas, câmera e os três estilos.

1. Identificar e registrar os arquivos: Pricedown histórica, Hapna/RDR Lino e sprites GTA/RDR2; manter autoria, versões, hashes e avisos.
2. Preparar TTFs para UI e PBF SDF para mapas, preservando os contornos reais e usando Noto apenas quando falta caractere. Roteamento HTTP local por interceptor/URLProtocol, sem servidor temporário.
3. Calibrar GTA: cinza urbano, prédios claros, verde profundo, preto nas vias, texto branco com halo preto, nomes de ruas prioritários e sentidos baseados somente em oneway real.
4. Incluir ensino, cultura e culto, conservar IDs anteriores e migrar preferências sem reativar a escolha todos-desligados. Distinguir fonte mundial da cobertura do snapshot offline.
5. Aplicar fontes à UI nativa, preservar símbolos de sistema e controles do host Android Auto. Painel com rolagem coordenada e rodapé fixo em área segura.
6. Verificar dados/arte, núcleo Swift, JVM, renderer Android e pacote iOS. Registrar as verificações Apple pendentes para o Mac do amigo; entregar fonte iOS completa e APK, mantendo o pacote original separado do código público.

Escolhas de implementação: aplicar a família Pricedown à UI GTA inteira é uma escolha do NavSkin; o jogo tem múltiplos estilos tipográficos. RDR Lino é uma família real do jogo, mas seu papel como lettering geográfico exato não foi comprovado. Não se declarou fonte extraída ou sprite Rockstar como CC0.
