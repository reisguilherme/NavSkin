# Eight-theme shared map assets

The active catalog is GTA SA, Rosa Pop, RDR2, Super Mario World, Cyberpunk 2077, Pip-Boy, Hollow Knight and Crossy Road. Minecraft and GTA V remain draft source material and are not packaged as selectable themes.

The three collection studies approved in the browser are promoted into `scripts/theme-art/`. Their original procedural phosphor symbols, ink textures, voxel trees and toy-building silhouettes are preserved. `collection-art.mjs` adapts semantic icon aliases, fonts and worldwide name fallbacks. `prepare-collection-assets.mjs` emits editable SVG pixel geometry, palettes, navigation catalog entries and explicit font provenance. These are authored adaptations, not extracted Fallout, Hollow Knight or Crossy Road game assets. Pip-Boy borrows the existing Blender Pro profile; Hollow Knight borrows the existing serif profile; Crossy Road retains Noto Sans and system interface typography. Font notices remain intact.

Run `npm run assets:collection` to reproduce shared source metadata, Android resources, previews and iOS resources. This needs the existing local original-asset/font pack; it downloads nothing and does not build an APK or IPA. The font import pipeline also reapplies the collection profiles so that regenerating the older game pack does not remove them. Existing source artwork, including the east-facing SMW traffic arrow and north-facing navigation vehicle, is not rewritten.

Every day/night and world/offline style contains optional `navskin-3d-` fill-extrusion layers, initially hidden. They follow only the existing visible building footprint buckets, including the exact local/world replacement filters. The hidden duplicate OSM buildings never produce volumes. Heights use `height`, `render_height` or levels × 3 where available, displayed within 5–120 metres. Missing values produce deterministic illustrative 6–25 metre volumes. These are visual aids, not a survey of building height. Crossy Road has flat rooftops in 2D; the same optional volume contract controls its 3D view.

Atlas packing retains each artwork's original dimensions instead of shrinking paper and tree tiles into a 32-pixel POI cell. Collection preview captures are recorded as browser rendering of the approved Goiânia study, with exact source image hashes and camera metadata. The five existing previews remain Native captures. The previews are not evidence of Android Auto or CarPlay rendering.

Validation covers the 32 styles, eight catalogs, real geographical sources, road grades and directions, all semantic POI groups, exact approved @2x atlas pixels, optional volume filters/heights, SMW arrow orientation, font notices and matching Android/iOS bundles. Native device validation remains separate. Native offline GeoJSON polygons use solid area colors with the approved contour strokes because patterned buckets can disappear after repeated style switches. Vector building materials, background textures and POI art remain. World styles and browser proposals retain the full material textures. This source-specific compatibility adjustment also remains intact for legacy themes.
