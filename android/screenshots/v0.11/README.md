# Capturas nativas 0.11

`v011-catalog/` contém os oito temas em perspectiva, renderizados no emulador Android API 36 com MapLibre Native e GPU host. Os prédios usam contornos reais; alturas podem ser ilustrativas. O teste compara pixels com e sem volumes na mesma câmera para comprovar geometria 3D, além de validar a volta para 2D.

Não são imagens geradas por IA. As telas são evidência do renderer; testes do GPS e da interface Vibing estão registrados na [validação](../../docs/VALIDATION-v0.11.md).
