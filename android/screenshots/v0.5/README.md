# São Paulo · NavSkin 0.5.0

Capturas produzidas pelo MapLibre Native no emulador Android API36 com GPU host. São Paulo fica fora do recorte offline de Goiânia. As imagens usam o serviço mundial real do OpenFreeMap, sem tiles de teste.

Os arquivos world-sao-paulo-gta.png, world-sao-paulo-rosa.png e world-sao-paulo-rdr2.png mostram os três temas. A imagem world-sao-paulo-rdr2-after-offline.png registra o retorno ao mundial após trocar a cobertura. Os marcadores de salvo presentes são dados criados apenas para validação e removidos pelo teste.

Este teste é de renderização Android. Não valida a UI do iOS, Android Auto/DHU nem navegação em veículo físico.
