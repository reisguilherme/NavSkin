As imagens `nav-*` usam replay de desenvolvimento, identificado como SIMULAÇÃO GPS. Seus valores são sintéticos. A captura `nav-gta-player-simulation.png` registrou o marcador antes de todos os tiles do fundo carregarem; a exploração GTA acima registra o mapa completo. Os demais arquivos documentam filtros e variantes noturnas nos testes de renderização.
